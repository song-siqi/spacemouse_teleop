# 独立末端位姿移动

输入基座坐标系下的绝对 `[x, y, z, roll, pitch, yaw]`，XYZ 单位 **mm**，RPY 单位 **度**。脚本从当前位置执行一次由控制器规划的末端直线运动，然后检查实际到位结果。不需要 SpaceMouse，不复位，不操作夹爪、负载或 TCP 配置，也不启动相机或采集。

## 调用

使用仓库已有 `.venv` 和 `xarm-python-sdk==1.18.4`，无需重新安装包入口。可从其他仓库使用绝对路径调用。

首先可以离线查看参数和拟发送接口。下面的目标仅为格式示例，没有经过现场路径验证：

```bash
/home/siqis3/workspace/spacemouse_teleop/scripts/run_xarm_move_to_pose.sh \
  --pose 250 0 300 180 0 0 --dry-run
```

实际运动时，将六个占位符替换为你的目标，去掉 `--dry-run` 即直接执行，没有二次确认：

```bash
/home/siqis3/workspace/spacemouse_teleop/scripts/run_xarm_move_to_pose.sh \
  --pose X Y Z ROLL PITCH YAW --speed 10 --accel 50 --timeout 120
```

`X Y Z ROLL PITCH YAW` 是需要替换的占位符。运行前退出其他控制程序；默认没有其他程序同时控制机器人。

| 参数 | 默认值 | 含义 |
|---|---|---|
| `--ip` | `192.168.1.209` | 控制器地址 |
| `--speed` | `10` | SDK 笛卡尔速度，mm/s |
| `--accel` | `50` | SDK 笛卡尔加速度，mm/s² |
| `--timeout` | `120` | 运动下发至完成验证的期限，秒 |
| `--position-tolerance` | `2` | XYZ 欧氏距离容差，mm |
| `--orientation-tolerance` | `1` | 完整姿态旋转夹角容差，度 |
| `--log` | 仓库 `logs/xarm_move_to_pose_*.jsonl` | 独立新文件；显式相对路径按调用者工作目录解释 |
| `--dry-run` | 关闭 | 不导入 SDK、不连接硬件，只检查参数和展示调用 |

速度／加速度超出当前 SDK 支持范围时会报错，避免 SDK 静默调整成不同于输入的值。速度参数不代表可独立指定的旋转速度上限。纯朝向变化同样交给控制器插补；最终角度检查使用旋转矩阵，支持 ±180° 等价表示。到位容差是验收条件，不是机器人精度承诺。

## 执行约定

- 要求 xArm6 静止、无待执行运动、无错误或警告。不自动清错，不接管活动任务。
- 从 `configs/spacemouse_xarm6_demo.json` 读取预期工具配置：当前 TCP offset 为 `[0,0,172,0,0,0]` mm/rad，负载与质心为 `[0.991,14.5,-3.23,61.24]` kg/mm。TCP 比较容差为 `1e-6` mm/rad，负载与质心为 0.01 kg / 1 mm；world offset 仍要求为零。只检查并记录，不修改控制器配置。
- 输入 pose 现在表示上述标定 TCP 的目标。旧零 TCP offset 下的 XYZ 与新 TCP XYZ 不能直接等同；要复现相同机械臂位置，需要使用新 TCP 的实际读数或按工具变换重新计算。
- SDK 的完整 rich 报告提供机器人类型、模式、工具／基座偏移、负载和使能状态；缺失字段或超过 1 秒未更新会失败，不能把默认零当成已读取的配置。
- 目标先经过逆运动学与关节限位预检；通过后使能运动、切换 Mode 0 并确认，发送一次 `set_position(..., relative=False, is_radian=False, radius=-1, wait=False)`。
- 以目标 20 Hz 主动查询位置、状态、待执行命令数和错误／警告，实际频率受通信耗时限制。SDK 事务设为 1 秒超时，连接、初始化和清理另有耗时。
- ACK 只表示指令响应。只有控制器停止、队列为空、实际位置与朝向误差均满足条件，并在至少 0.3 秒的新查询中持续成立，才返回成功。
- 成功后保持使能的正常位置控制静止状态，断开连接；下一实验程序自行初始化需要的模式。失败、Ctrl-C 或 SIGTERM 若可能已经发送运动，则先尝试 `set_state(4)` 并查询确认，再释放资源。停止无法确认会明确报告。
- 位置运动不具有遥操速度指令的短有效期。通信彻底断开、强制杀进程或主机失电时，脚本不能保证控制器立即停止；退出连接不能作为停止命令。

本工具没有环境模型，不自动避开桌面、相机或物体。目标逆解成功不证明整条直线路径可执行；失败不会重试运动，也不会自动改成关节路径。

## 输出与实现隔离

每次调用创建独立 JSONL 文件，不覆盖旧日志或修改 `latest` 链接。记录目标／参数、初始实际位姿与关节、SDK／固件版本、TCP／基座偏移、负载、预检结果、下发与返回、监测误差、最终结果和异常退出。dry-run 明确标记未检查可达性。

退出码：`0` 成功（或离线预览完成）；`1` 运行失败；`2` 参数错误；`130` Ctrl-C；`143` SIGTERM。其他仓库可据此决定是否继续实验。

SDK 内部适配只作用于本脚本创建的实例：使能指令保留官方编码但使用 1 秒超时，位置指令内部硬编码的 10 秒应答等待也限制为 1 秒；位置接口的无期限同步等待替换为显式就绪检查。既有 SDK 后端、遥操、数据采集及配置均不改变。
