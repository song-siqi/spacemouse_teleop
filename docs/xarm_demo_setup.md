# 真机 demo：本机试运行

当前 demo 从当前位置启动，终端按 H 才打开夹爪并回 home。此流程由独立 `xarm_demo` 入口编排；配置为 `configs/spacemouse_xarm6_demo.json`，启动脚本为 `scripts/run_xarm_demo.sh`。公共 SDK 后端、原遥操入口、采集、固定朝向平移遥操和 move-to-pose 的流程保持原行为。基础控制与历史自动启动复位已有现场记录；本次 H 切换需单独现场验收。

## 启动

```bash
cd /home/siqis3/workspace/spacemouse_teleop_xarm_merge
./scripts/run_xarm_demo.sh
```

每次 live 启动顺序：连接/工具与状态检查 → 保持当前机械臂和夹爪位置 → 六轴回中、双键释放 → 开始六自由度遥操。启动不执行自动复位或打开夹爪；进入遥操时仍初始化原有夹爪控制。

在启动脚本的终端中按 **h 或 H**（无需回车）：停止遥操并关闭旧控制实例 → 新连接 → 打开夹爪并确认到位 → 低速回到配置中的 home → 停止确认 → 再次等待鼠标回中、双键释放 → 恢复遥操。**H 会先打开夹爪，可能释放当前夹持物体。** Home 当前关节目标为 `[0°, -60°, -30°, 0°, 90°, 0°]`，不会被启动位置覆盖。

复位期间 SpaceMouse 不发送运动或夹爪指令；重复 H 被丢弃，持续按住不会排队。完成后松开 H，回中并释放鼠标按钮才能继续。H 不是全局快捷键，终端必须有焦点；live 模式没有交互终端时会在连接硬件前报错。

默认 `--duration 0`，持续到 Ctrl-C。显式指定 `--duration 120` 时，累计回中等待与遥操时间两分钟；H 的停止交接、开夹爪及复位期间暂停计时，H 不重置累计时长。每次回中仍有配置中的启动超时。Ctrl-C、SIGTERM 或终端关闭都会先尝试停止机器人，再关闭输入、恢复终端并收尾日志；复位失败或超时直接退出，不恢复遥操。

复位复用原有关节路径，不自动规划避障。工具参数、输入时效及反馈检查保留。禁止其他程序同时控制机器人。

连接和检查通过后，鼠标回零且按钮释放即开始。首次完全静止的设备可能没有 HID 报告，轻推后回零一次即可。鼠标回零立即发送机械臂零速度。进入遥操后，**按住 button 0 打开，按住 button 1 关闭；松开或两键同时按下发送当前位置保持**。从双键状态释放一个按钮后，恢复剩下按钮的方向。采样前已释放的短点击不再触发延迟运动。

每次脚本调用保留一个独立 JSONL 会话，多次 H 不拆分日志。新增 `demo_phase`、`home_requested` 和每次激活参考关节记录。`logs/xarm_demo_latest.jsonl` 指向最近一轮。按 H 时沿用日志事件 `startup_gripper_open_started`、发送/位置反馈、`startup_gripper_open_completed`（失败为 `startup_gripper_open_failed`）、`homing_started`、每次复位发送、`homing_completed` 和实际开始遥操的反馈姿态。终端会显示速度上限、当前阶段和 H 操作提示。

离线预览：`./scripts/run_xarm_demo.sh --dry-run --duration 3`。不连接机器人或 HID；H 只记录模拟阶段切换。无交互终端的 dry-run 必须指定正数时长。新功能的假后端与 PTY 测试不替代现场验收：现场应从非 home 位置启动，完成遥操、H 复位、回中后继续，至少重复两轮。

夹爪粘有 tactile sensor，用户确认不能完全闭合。旧目标 0 在约 208 pulse 处受阻，因此 demo 暂将 `gripper.close_pulse` 设为 230，略留余量；该值尚待现场校准，不代表接触力限制。若当前位置已小于 230，可长按打开退回，关闭按钮不会继续给更小目标。

当前控制和限制的点是沿工具 Z 偏移 172 mm 的标定 TCP，旋转偏移为零。demo、平移遥操和采集采用此配置；指定 pose 脚本也读取 demo 中的工具参数。原零偏移配置下的 XYZ 不能直接作为同一物理起点使用；历史数据保持其原有 TCP 语义。更换工具后需要重新核对配置，完整现场验收仍单独记录。

## 初始化姿态与复位参数

`site.initial_joints_rad` 为复位目标；当前 demo 对应 `[0°, -60°, -30°, 0°, 90°, 0°]`。`robot.homing.enabled=true` 保留并验证复位参数；新 demo 仅在按 H 时调用复位。原遥操、采集和平移入口的启动复位行为不变。

- 夹爪启用时，先发送一次打开端点并最多等待 10 秒；实际位置、设备目标均需在打开目标 ±15 pulse 内，且 stopped 持续 0.2 秒。只有满足条件才允许机械臂进入复位模式。
- 15 pulse 容差兼容本机打开命令 850、设备目标 840、实际约 838–842 的观测；仅收到成功 ACK 或仅报告 stopped 均不算打开完成。
- 打开超时、受阻、报错、输入/反馈异常或 Ctrl-C 均终止此次 H 流程并退出，尝试保持夹爪当前位置，机械臂不开始复位。开夹爪的计时独立于后续机械臂 120 秒复位计时。

- 关节速度上限 0.1 rad/s（约 5.7°/s），关节加速度上限 0.2 rad/s²。
- 到位误差每轴不超过 0.005 rad（约 0.29°），持续稳定 0.3 秒后确认完成。
- 最长 120 秒（原为 30 秒），与复位后的遥操 `--duration` 独立；超时/状态故障/反馈过期/输入故障停止退出。
- 反馈接近期限、剩余时间不足以发送有效速度指令时，短暂等待下一帧并记录 `homing_waiting_feedback`；真正超过 0.25 秒反馈期限仍停止。
- 复位使用 Mode 4 关节速度及有限命令有效期，结束后主动停止，再在鼠标回零后进入 Mode 5 遥操。
- 复位时丢弃鼠标运动/夹爪意图；不会在复位完成前开始遥操。

本轮复位与遥操均不附加 TCP 包围盒限制；仍检查反馈、TCP/负载、速度/加速度和控制器错误。不会改写机器人的安全边界、缩减模式或碰撞参数。复位不包含完整场景碰撞路径规划。`--dry-run` 不执行夹爪或机械臂动作，H 只模拟流程切换。

state=5 是 MODE_CHANGED；启动支持这个静止状态，在参数与输入检查通过后初始化。运行中进入 state=5 仍停止退出。[UFACTORY 状态说明](https://docs.ufactory.cc/user_manual/ufactoryStudio/10.motion_mode_and_state.html)。
