# 真机 demo：本机试运行

真机基础 demo 已由用户完成测试：机械臂遥操、夹爪长按开合与保持，以及启动先开夹爪、再复位的完整顺序已有日志验证。当前配置关闭额外 TCP 位置包围盒，保留速度与反馈检查。独立配置为 `configs/spacemouse_xarm6_demo.json`，启动脚本为 `scripts/run_xarm_demo.sh`。

## 启动

```bash
cd /home/siqis3/workspace/spacemouse_teleop
./scripts/run_xarm_demo.sh
```

每次 live 启动顺序：连接/工具与状态检查 → 自动打开夹爪并确认到位 → 低速复位到初始化关节 → 到位并停止 → 鼠标回零、按钮释放 → 开始遥操。**启动会先打开夹爪、释放上次轨迹末尾夹持的物体，再移动机械臂回到初始化姿态。**

默认复位结束后运行 60 秒（含输入等待），可用 `--duration 120` 改为两分钟，或 `--duration 0` 不限总时长、由 Ctrl-C 结束。Ctrl-C 在复位和遥操阶段都执行停止。demo 的额外位置边界已关闭，TCP offset 和负载仍需匹配。复位失败或超时不会进入遥操。

连接和检查通过后，鼠标回零且按钮释放即开始。首次完全静止的设备可能没有 HID 报告，轻推后回零一次即可。鼠标回零立即发送机械臂零速度。进入遥操后，**按住 button 0 打开，按住 button 1 关闭；松开或两键同时按下发送当前位置保持**。从双键状态释放一个按钮后，恢复剩下按钮的方向。采样前已释放的短点击不再触发延迟运动。

每轮保留独立 JSONL 日志，`logs/xarm_demo_latest.jsonl` 指向最近一轮。日志记录 `startup_gripper_open_started`、发送/位置反馈、`startup_gripper_open_completed`（失败为 `startup_gripper_open_failed`）、`homing_started`、每次复位发送、`homing_completed` 和实际开始遥操的反馈姿态。终端会显示实际加载的速度上限、TCP 范围和启动策略。

零 TCP offset 表示此处控制和限制的点是法兰中心；正式工具标定和完整现场验收仍待后续。更换工具后需要更新对应配置。

## 初始化姿态与复位参数

`site.initial_joints_rad` 为复位目标；当前 demo 对应 `[0°, -60°, -30°, 0°, 90°, 0°]`。`robot.homing.enabled=true` 控制自动复位，demo 和正式真机模板均启用。

- 夹爪启用时，先发送一次打开端点并最多等待 10 秒；实际位置、设备目标均需在打开目标 ±15 pulse 内，且 stopped 持续 0.2 秒。只有满足条件才允许机械臂进入复位模式。
- 15 pulse 容差兼容本机打开命令 850、设备目标 840、实际约 838–842 的观测；仅收到成功 ACK 或仅报告 stopped 均不算打开完成。
- 打开超时、受阻、报错、输入/反馈异常或 Ctrl-C 均终止启动，尝试保持夹爪当前位置，机械臂不开始复位。开夹爪的计时独立于后续机械臂 120 秒复位计时。

- 关节速度上限 0.1 rad/s（约 5.7°/s），关节加速度上限 0.2 rad/s²。
- 到位误差每轴不超过 0.005 rad（约 0.29°），持续稳定 0.3 秒后确认完成。
- 最长 120 秒（原为 30 秒），与复位后的遥操 `--duration` 独立；超时/状态故障/反馈过期/输入故障停止退出。
- 反馈接近期限、剩余时间不足以发送有效速度指令时，短暂等待下一帧并记录 `homing_waiting_feedback`；真正超过 0.25 秒反馈期限仍停止。
- 复位使用 Mode 4 关节速度及有限命令有效期，结束后主动停止，再在鼠标回零后进入 Mode 5 遥操。
- 复位时丢弃鼠标运动/夹爪意图；不会在复位完成前开始遥操。

本轮复位与遥操均不附加 TCP 包围盒限制；仍检查反馈、TCP/负载、速度/加速度和控制器错误。不会改写机器人的安全边界、缩减模式或碰撞参数。复位不包含完整场景碰撞路径规划。`--dry-run` 完全跳过自动开夹爪与物理复位。

state=5 是 MODE_CHANGED；启动支持这个静止状态，在参数与输入检查通过后初始化。运行中进入 state=5 仍停止退出。[UFACTORY 状态说明](https://docs.ufactory.cc/user_manual/ufactoryStudio/10.motion_mode_and_state.html)。
